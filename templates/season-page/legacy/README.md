# 一次性脚本（不参与 build.py）

这两个脚本是为「2026–27 雪季对比」那一次交付临时写的，功能已被正式生成器覆盖，
留在这里只为查证「当时那个数字是怎么来的」。**新雪季不要用**。
本目录被 `tools/package.py` 排除，不进分发包。

| 文件 | 它当时干什么 | 现在该用什么 |
|---|---|---|
| `build_cmp.py` | 重建 `dist/七雪场对比-2027元旦.html` 的对比面板（`pane-cmp`）。里面写死了 7 个雪场的住宿依据、机场车程、将军山四种去程走法等静态事实 | `build_season.py` 的 `sections()` —— 全部从 `season-data.json` 生成，无静态事实 |
| `verify_season.py` | 轻量抽查：异常串、标签配平、表 1 / 表 4 的单元格数、每个格子的元/雪日在页面里出现 | `verify_season_all.py` —— 七节，含三方一致与逐格比对 |

两者的路径都硬编码在 `D:/Project/other/ski-trip-planner` 与本项目的 `dist/` 文件名上，
换项目必然失效。要复用其中某段逻辑，先把它搬进对应的正式生成器再改。
