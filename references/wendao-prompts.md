# 携程问道：自然语言查询模板

问道**不是**票价数据源，它是「配额宽松、能快速给你一个大致判断」的粗筛工具。用在两个环节：

1. **机场粗筛** —— 雪场周边有 3–4 个候选机场，先看哪个值得深入；
2. **行程骨架** —— 定「周五晚走还是周六早走」「周日下午回还是周一早回」这类骨架决策。

精确票价一律走飞常准（`scripts/flight_query.js`）。**问道的结果不进 config。**

---

## 调用方式

原始 HTTP 接口，不封 CLI。key 从环境变量 `WENDAO_API_KEY` 读取。

```bash
curl -sS -X POST 'https://externalcallback.ctrip.com/skills/api/crew/skillhub/searchInfo' \
  -H 'Content-Type: application/json' \
  -d "{\"inputs\":{\"token\":\"$WENDAO_API_KEY\",\"query\":\"<你的自然语言问题>\"}}" \
  | node -e "let s='';process.stdin.on('data',d=>s+=d).on('end',()=>console.log(JSON.parse(s).result))"
```

响应是 `{ result, messages, state, events, error }`，**正文在 `result`**，其余字段是内部日志。

**HTTP 200 不等于成功。** `error` 为 `null` 但 `result` 可能只有一句「您的问题似乎与旅行服务无关」——必须判 `result` 内容，不能只看状态码。

### 写法上的三个坑

| 坑 | 表现 | 对策 |
|---|---|---|
| 指令式措辞被审核拦 | 写「硬性要求 / 禁止省略 / 禁止折叠」→ 直接返回「与旅行服务无关」 | 用用户口吻：「三个机场我都要看，别只挑一个给我」 |
| 开放式提问只给代表 | 问「有哪些航班」→ 每类给 2–4 个 | 给它候选清单让它逐条核对 |
| 一次问太多 | 直飞 + 中转 + 经停一起问，结果反而更少 | 一次只问一件事 |

## 提示词 1：机场粗筛

**用在**：第 1 步，候选机场 ≥ 2 个时。

```
我打算 <日期> 从 <出发城市> 飞去 <雪场所在城市或区域> 滑雪，<雪场名> 附近有这几个机场：
<机场A>、<机场B>、<机场C>。帮我看看这一天从 <出发城市> 飞到这几个机场分别有哪些航班，
各大概有多少班、最早一班几点落地、经济舱大概什么价位区间。这几个机场我都要看，别只挑一个给我。
```

**只取三件事**：

- 有没有航班（有 / 没有 / 很少）
- 大致班次量（几班，不必精确）
- 最早落地时刻（决定当天能不能进场）

票价只当量级参考——问道给的是票面价、不含机建燃油，且常给「暂无」。

**下一步**：入围的 2–3 个机场，用 `node scripts/amap_route.js` 逐个算车程（高德额度大，不心疼），再把「车程 + 班次量 + 价位量级」交给用户选。

## 提示词 2：行程骨架

**用在**：第 1 步第 9 条，出骨架确认卡之前。

```
我想 <周末日期> 去 <雪场名> 滑雪，从 <出发城市> 飞 <机场>。帮我理一下那两天航班的大致时段分布：
早上、中午、下午、晚上各有几班，最早一班几点起飞、最晚一班几点落地，有没有红眼航班。
另外这周末哪天航班明显更贵或者明显更少？
```

**用途**：决定骨架方向，不用于精确比价。

- 「周五有没有晚班」→ 决定去程能不能请假 0 天；
- 「周日最晚几点落地」→ 决定返程要不要占周一；
- 「哪天更贵」→ 决定要不要把周末往前挪一周。

**下一步**：骨架定下来后，用 `flight_query.js --weekend --leave-days` 拿真实数据。

---

## 提示词 3：执飞校验

**用在**：第 3 步之后，对最终 1–2 个候选做确认。

```
<日期> <航班号> 从 <出发地> 飞 <到达地>，这天执飞吗？计划几点起飞几点落地？
```

这是问道**唯一比飞常准更值得信的场景**——它在「这天飞不飞」上判断准确（实测与飞常准库存一致）。但下单前仍要用 `getBuyTicketUrl` 或航司官网复核。

---

## 字段可信度

| 字段 | 可信度 | 处理 |
|---|---|---|
| 是否执飞 | 较高 | 可采信，下单前仍要复核 |
| 时刻 | 一般准确 | 以飞常准为准 |
| 航班号 | **偶发出错** | 必须回查飞常准 |
| 票面价 | 量级可信 | 精确比价用飞常准含税价 |
| 中转方案覆盖 | **仅约 9%** | 不能用于枚举中转方案 |
| 余票 | 不提供 | 用飞常准 `seats` |

---

## 配额

问道按**日配额**，比飞常准（100 积分/月）宽松得多，适合反复试探。但：

- 同一 query 两次结果可能不同，**不可复现**；
- 响应 21–57 秒，比飞常准（3 秒内）慢一个数量级；
- 超配额会返回配额类提示，不是报错中断。

所以：**粗筛随便问，定稿必须回飞常准。**
